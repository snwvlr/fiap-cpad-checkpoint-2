# Compras para o PC

Checkpoint 2 de Cross-Platform Application Development (FIAP).

Aplicativo em React Native com Expo para montar uma lista de compras de peças de computador. Digite uma peça, toque em **Adicionar** e ela aparece na lista. Os itens são guardados em memória com `useState` e exibidos com `FlatList`.

## Como executar

```bash
npm install
npm start
```

Depois, abra o aplicativo no Expo Go ou em um emulador. Para executar no navegador, use `npm run web`.
